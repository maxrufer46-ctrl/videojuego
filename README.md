# Street Heat: Most Hunted

Juego de carreras arcade 3D para Android, inspirado en las persecuciones y carreras callejeras clásicas, pero con identidad y contenido originales.

## Estado actual — v0.1

Incluye conducción arcade 3D, aceleración, freno/reversa, dirección, drift, nitro recargable, cámara perseguidora, velocímetro, sistema HEAT 1–5, patrulla policial y controles táctiles para Android.

## Cómo probarlo

1. Crea un proyecto **Unity 3D Core**.
2. Copia la carpeta `Assets` de este repositorio dentro del proyecto.
3. Abre Unity.
4. Usa **Street Heat > Build Demo Scene**.
5. Presiona **Play**.

### Controles PC

- W / Flecha arriba: acelerar
- S / Flecha abajo: frenar / reversa
- A / D o flechas: girar
- Shift izquierdo: nitro
- Espacio: drift
